# MongoDB User Management App

Scaffolded full-stack app: Express + MongoDB backend and React frontend.

See `backend/README.md` and `frontend/README.md` for run instructions.

Docker (build & run)

The repository includes `Dockerfile`s and a `docker-compose.yml` to run the app and a MongoDB service.

Build and run with Docker Compose:

```bash
docker-compose build
docker-compose up
```

Frontend will be available at `http://localhost:3000` and backend at `http://localhost:5000`.

If you prefer to run services individually, see the backends' and frontends' READMEs.
